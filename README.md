# smooks — outdoors resource directory

Source repository for the [smooks.co.uk](https://smooks.co.uk/) outdoor resource directory.

The live site was previously deployed to Cloudflare Pages by direct upload. This repository is being reconstructed from the public website, preserving its published resource information. It is **not** the original unpublished source code.

The original live Cloudflare deployment is not connected to this repository. Changes here will **not** change the live website until a deployment is deliberately configured and authorised.

The initial reconstruction will include the 16 published resource categories, links, and filters, as well as accessible, responsive source code.
